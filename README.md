# Nine Men's Morris - Difficulty Deluxe

古代ローマ時代から親しまれている伝統的な2人用アブストラクト・ストラテジーゲーム「ナイン・メンズ・モリス（Nine Men's Morris）」を、PythonとPygameで再現したデスクトップアプリケーションです。3段階のAI思考エンジンを搭載し、初心者から熟練者まで楽しめる仕様になっています。

## 🎮 ゲームルール概要

各プレイヤーは 9つの駒 を持ち、盤面にある24個の交点（ノード）を使って戦います。

### 1. ドロップフェーズ（配置）
* プレイヤーとAIが交互に、空いている交点に1つずつ駒を配置します（計9手ずつ）。
* すべての駒を置き終えると「ムーブフェーズ」に移行します。

### 2. ムーブフェーズ（移動）
* 自分の番に、自分の駒を1つ選択し、線でつながった隣接する空き交点へ1マス移動させます。
* 自分の駒が残り **3つ** になったプレイヤーは「フライング能力」を獲得し、隣接条件を無視して盤面上のあらゆる空き交点へワープできるようになります。

### 3. ミル（Mill）の結成と駒の除去
* 縦または横に自分の駒が3つ直線に並ぶと**「ミル（Mill）」**が成立します。
* ミルを成立させたプレイヤーは、**相手の盤上にある駒を1つ選んで除去（キャプチャ）**できます。
* *ルール上の注意:* 相手の駒がすべてミルを構成している場合を除き、原則として「すでに相手のミルの一部になっている駒」を選択して除去することはできません。

### 🏆 勝利条件
以下のいずれかの条件を満たしたプレイヤーが勝利します。
1. 相手の駒を **2つ** 以下にまで減らす（相手はミルを作れなくなります）。
2. 相手の番になった際、相手のすべての駒がブロックされており、**合法な移動操作が不可能（詰み）**にする。

## 🤖 AI難易度について

タイトル画面で以下の3つの難易度を選択可能です。

* **EASY (初級)**: 約30%の確率で完全ランダムな手を指します。基本的なルールの把握や練習に最適です。
* **NORMAL (中級)**: 即座にミルを作れる手を最優先し、それ以外は現在の盤面評価（駒数やミルの優位性）を計算して最善の手を選択します。
* **HARD (上級)**: 簡易ミニマックスアルゴリズム（1手先読みシミュレーション）を搭載。プレイヤーが次に指すであろう妨害手や最善手を予測し、先を読んだロジスティックな布陣を展開してきます。

## ⚙️ 動作環境とセットアップ

### 前提条件
システムに **Python 3.x** がインストールされている必要があります。

### 1. 依存ライブラリのインストール
外部ライブラリとして `pygame` を使用しています。未インストールの場合は、ターミナル（またはコマンドプロンプト）で以下のコマンドを実行してください。

```bash
pip install pygame
2. ディレクトリ構成
快適にプレイするため、以下のファイル構造を推奨します。効果音やフォントファイルが存在しない場合でも、自動的にフォールバック（代替処理）が働き、サイレントモードおよびシステムフォントでの日本語表示で起動します。

Plaintext
📂 ナインメンズモリス/

プログラムが配置されているディレクトリで、以下のコマンドを実行します。

Bash
python main.py
🛠️ トラブルシューティング（文字化け・クラッシュ対策）
本バージョンには、Pygame環境で発生しやすい「日本語の豆腐文字（🔲文字化け）」を防ぐ堅牢な自動選定ロジックが組み込まれています。

フォントの優先読込: 実行フォルダ内に NotoSansJP-Regular.ttf がある場合は最優先で読み込みます。環境を問わず美しい文字表示を保証するため、このフォントファイルの同封を推奨します。

システムフォント自動検出: フォントファイルがない場合、OS内部のレジストリ（Windows: MS Gothic, Meiryo / Mac: Hiragino / Linux: Noto Sans CJK 等）を自動巡回して日本語フォントをアタッチします。
